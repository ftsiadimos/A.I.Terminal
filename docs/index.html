A.I.Terminal Desktop

Native GNOME desktop app combining AI-assisted natural language command execution with terminal-style output, SSH connectivity, and Ollama integration.

Key Features

  • Native GTK4 + Libadwaita user interface for GNOME
  • SSH management for local and remote command execution
  • AI-powered natural language prompts via Ollama
  • Live command output streaming with analysis and history
  • Persistent settings and easy re-use across sessions

Getting Started

The easiest way to install is via the prebuilt RPM package in AIDesktop/packaging/, or run the bundled install.sh script for Fedora systems.

Once installed, launch the app from the desktop entry or run:

python3 AIDesktop/main.py

Usage Overview

Use the app to connect to SSH servers, configure Ollama, and send natural language requests. The assistant can execute shell-safe commands automatically or interpret requests like "show disk usage" and translate them into shell actions.

  • Type plain shell commands to execute directly
  • Use natural language prompts for AI assistance
  • Prefix commands with ai: to force AI processing
  • Toggle AI assistance in settings when needed

Recommended Setup

  • Fedora or GNOME-based Linux distribution
  • Python 3.9+ with GTK4 and PyGObject
  • Ollama installed and serving a compatible model
  • SSH server access for remote execution

Configuration is saved under ~/.config/aiterminal-desktop/settings.json.
